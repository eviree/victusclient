# Victus Client mod (Fabric 1.21.1 -> 1.21.11)

* Right Shift in game -> Victus menu (sidebar tabs, animated switches, info panel, profiles, settings)
* Victus title screen (animated background + logo)
* ~40 working mods + a roadmap list (marked SOON in the menu)
* Special mod: Victus Momentum

Build: push to GitHub, tag `vX.Y.Z`; Actions builds one jar per Minecraft range (see versions/).
